# FinWise: AI-Powered Personal Finance Planner for Youth

FinWise is an easy-to-use, intelligent financial planning web app designed for young individuals. It helps users manage their budget, track expenses, set savings goals, and get AI-powered tips to build smart money habits.

---

## 🚀 Features

- 🔐 **User Authentication** using Firebase (Login & Signup)
- 📊 **Track Monthly Budgets & Expenses**
- 🎯 **Goal-Based Financial Planning**
- 🤖 **AI-Powered Tips** for saving and spending wisely
- 📁 **Export Personalized Financial Reports** as PDF
- ☁️ **Cloud Storage** of user data using Firebase Firestore

---

## 🛠️ Built With

- **Python** – Core logic & backend
- **Streamlit** – Frontend web UI
- **Firebase** – Authentication & Firestore database
- **Fpdf2** – For generating PDF reports
- **Matplotlib/Plotly** – For visual charts
