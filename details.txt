✅ Step 1: Setup Firebase Auth with Streamlit
We’ll use a helpful library: streamlit-firebase-auth
Let’s get Firebase Auth working with:

✅ Email/password login/signup

✅ Secure session handling

✅ Optionally: Google login (later)



✅ 1. Create Firebase Project
Go to Firebase Console

Click “Add project” → Name it: FinWise

Go to Authentication > Sign-in Method

Enable Email/Password

(Optional) Enable Google Sign-In

Go to Project Settings > Web App

Register app → get API keys, authDomain, projectId, etc.


streamlit run app.py
